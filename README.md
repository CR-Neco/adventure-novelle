AI-Generated Fantasy-Adventure with Human-Played Character

## Die Glocken von Dornwacht

Eine fortlaufende interaktive Fantasy-Novelle mit Skarra „Blackheart“ aus Guild Wars 2 als Spielerfigur. Vier eigenständige Begleiterinnen – Minthara, Triss Merigold, Brienne von Tarth und Magrat Knoblauch – werden von der Spielleitung geführt.

**Spielprinzip:** Die Spielerfigur spricht und handelt nur auf Eingabe des Spielers. Die Begleiterinnen entwickeln eigene Beziehungen, Ansichten und Konflikte. Die Handlung bleibt offen; bereits gespielte Ereignisse werden nicht nachträglich verändert.

**Spoiler-Schutz:** Das Repository enthält nur dem Spieler bekannte Informationen. Verborgene Motive, geheime Plotpläne und künftige Wendungen gehören nicht hinein.

**Aktueller Haltepunkt:** Am alten Nordweg verlangt ein vermummter Fremder eine von Skarras Knochenkundschaftern erbeutete Ledertasche zurück. Skarra ist am Zug.
