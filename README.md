# adventure-novelle

AI-Generated Fantasy-Adventure with Human-Played Character

## Die Glocken von Dornwacht

Eine fortlaufende interaktive Fantasy-Novelle. **Skarra „Blackheart“** aus Guild Wars 2 wird ausschließlich vom Spieler gesteuert. Die Spielleitung übernimmt die Welt sowie **Minthara, Triss Merigold, Brienne von Tarth und Magrat Knoblauch**.

### Einstieg für einen neuen Abenteuer-Chat

> Übernimm die Spielleitung von **„Die Glocken von Dornwacht“**. Öffne das private GitHub-Repository **`CR-Neco/adventure-novelle`** und lies dort zuerst **`SPIELLEITUNG_START.md`** sowie die darin verlinkten Dateien, insbesondere den Kampagnenstand und die Word-Romanfassung. Halte alle Regeln und den Kanon ein. **Warte anschließend auf Skarras nächsten Zug**, ohne die Szene vorwegzunehmen.

### Prinzipien

**Der Spieler entscheidet ausschließlich für Skarra.** Alle anderen Figuren handeln eigenständig. Die Gruppendynamik, nicht die maximale Kampfstärke, steht im Mittelpunkt.

**OOC:** `(OOC: …)` (Spieler) bzw. `(OOC – Spielleiter: …)` (Spielleitung).

**Romanfassung:** tatsächliche Szenen und Dialoge bewahren, Spielerbeiträge marineblau. Die Word-Datei wird nach Spielsitzungen fortgeschrieben.

**Spoiler-Schutz:** Das Repository enthält nur Spielerwissen, keine geheimen Spielleiterpläne.

**Aktueller Haltepunkt:** Am alten Nordweg verlangt ein vermummter Fremder eine von Skarras Knochenkundschaftern erbeutete Ledertasche zurück. **Skarra ist am Zug.**
