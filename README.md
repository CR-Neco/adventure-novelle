# adventure-novelle

AI-Generated Fantasy-Adventure with Human-Played Character

## Die Glocken von Dornwacht

Eine fortlaufende interaktive Fantasy-Novelle. **Skarra „Blackheart“** aus Guild Wars 2 wird ausschließlich vom Spieler gesteuert. Die Spielleitung übernimmt die Welt sowie **Minthara, Triss Merigold, Brienne von Tarth und Magrat Knoblauch**.

### Einstieg für einen neuen Abenteuer-Chat

> Übernimm die Spielleitung von **„Die Glocken von Dornwacht“**. Öffne das private GitHub-Repository **`CR-Neco/adventure-novelle`** und lies dort zuerst **`SPIELLEITUNG_START.md`** sowie die darin verlinkten Dateien, insbesondere den Kampagnenstand und den vollständigen Romantext in `roman/Die_Glocken_von_Dornwacht.md`. Halte alle Regeln und den Kanon ein. **Warte anschließend auf Skarras nächsten Zug**, ohne die Szene vorwegzunehmen.

### Prinzipien

**Der Spieler entscheidet ausschließlich für Skarra.** Alle anderen Figuren handeln eigenständig. Die Gruppendynamik, nicht die maximale Kampfstärke, steht im Mittelpunkt.

**OOC:** `(OOC: …)` (Spieler) bzw. `(OOC – Spielleiter: …)` (Spielleitung).

**Romanfassung:** tatsächliche Szenen und Dialoge bewahren, Spielerbeiträge marineblau. Die Markdown-Datei ist aktuell. Die Word-Datei bleibt auf Wunsch vom 14. Oktober 2026 vorerst auf dem Stand der ersten Sitzung; Synchronisierung folgt später.

**Spoiler-Schutz:** Das Repository enthält nur Spielerwissen, keine geheimen Spielleiterpläne.

**Aktueller Haltepunkt (Zwischenstand 16. Oktober 2026):** Abend des ersten Reisetages, Köhlerstelle am östlichen Waldumweg nach dem Gutshof. Skarra hat dem Lager bereits zugestimmt und eine neue Fleischwurmwache angeordnet. Nächste Szene: Lager einrichten und absichern. Golem Alfred ist entlassen, Bero und Tamm ziehen den Wagen.
