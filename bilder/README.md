# Illustrationen und Referenzbilder

Hier liegen die vom Spieler bereitgestellten Originalreferenzen und spätere Illustrationen.

- `skarra/`: verbindliche visuelle Referenzen der Spielerfigur.
- `gruppe/`: künftige Bilder der Begleiterinnen oder Gruppenbilder.
- `schauplaetze/`: künftige Szenen- und Ortsillustrationen.

Bilder werden **nicht** automatisch ausgetauscht oder neu interpretiert. Für neue Bilder gilt die jeweils vorhandene Charakterreferenz. Illustrationen nur auf ausdrücklichen Wunsch des Spielers.
